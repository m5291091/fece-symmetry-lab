# 診断素材の撮影プロトコル

対称度指標の**診断測定**（`docs/symmetry-metric-measurements.md`）で使う実写素材を、テイク間で比較できる形で撮るための手順。アプリの利用者向けの案内ではなく、開発者が測定素材を撮るときの手順である。

プロダクト仕様の正本は `requirement.md`。本書は仕様ではなく作業手順であり、要件 ID を定義しない。

**本書の閾値は take01〜take03 の実測ばらつき（§14.1）から引いた作業用の値である。この値を守れば表示値のセッション間ばらつきが消える、ということは検証されていない。** それを確かめるのが、この手順で撮る take04 以降の目的である。

---

## 1. なぜ必要か

同一人物・同一の顔を 3 回撮った結果（`docs/symmetry-metric-measurements.md` §14.4、直叩き・IMAGE モード・全検出フレーム）:

```
3D 表示値の中央値   take01 98.280   take02 98.249   take03 98.523pt
                    テイク間の全幅 0.273pt / 標準偏差 0.150pt（n=3）
```

take01 と take02 だけなら 0.031pt だった差が、3 本目を入れると 0.273pt になる。**顔は変わっていないので、この 0.27pt は撮り方か、撮り方では説明できない何かである。** 前者なら揃えれば消せる。本書は「揃える」側の手順を固定して、その切り分けを可能にする。

`requirement.md` のリスク表 R-02（姿勢・照明・camera 差が顔差より大きい）に対応する作業でもある。

## 2. take01〜take03 で守られていた条件

3 本とも同じだった項目。**新しいテイクでも同じにすること。**

| 項目 | take01〜03 の実測 |
|---|---|
| 被写体 | 1 名（同一人物） |
| カメラ | 同一・1280x720 |
| フレームレート | 29.97〜30.00 fps |
| 尺 | 19.50〜20.02 秒（585〜600 フレーム） |
| 検出率（顔 1 つ以上） | 100.00% |
| 単一顔率 | 100.00% |
| 複数顔率 | 0.00% |

検出率と単一顔率が 3 本とも 100% だったのは重要である。**「検出できたか」はテイク間の差を説明しない。** 説明候補は次節に挙げる項目だけである。

## 4. 手順

### 4.1 準備（初回に 1 度、以後は再現するだけ）

1. **カメラを固定する。** 三脚か固定台。手持ち・ノート PC の開閉角に依存する内蔵カメラは使わない。開閉角が変わると距離と pitch が同時に動く。
2. **カメラの高さを目の高さに合わせ、床に対して水平にする。** pitch のオフセットはここで決まる。
3. **被写体の位置に印を付ける。** 椅子の脚位置と背もたれ角度を床にマーキングする。距離（＝ IOD の画素数）はこれで決まる。
4. **照明を固定する。** 正面からの拡散光を 1 灯以上。位置・高さ・向き・出力をメモするか、床にマーキングする。窓からの自然光は時間帯で変わるので、遮光して使わない。
5. **カメラの自動制御を切る。** 自動露出・自動ホワイトバランス・自動フォーカスをすべて手動に固定し、設定値を記録する。**自動露出が入っていると、被写体が少し動いただけで輝度が動く。**
6. **解像度とフレームレートを 1280x720 / 30fps に固定する。**

### 4.2 撮影のたびに

1. 4.1 の印の位置に座る。背もたれに背を付け、足を床に付ける。
2. カメラのレンズを見る。**視線を動かさない。** 画面や手元を見ると yaw と pitch が動く。
3. 顎を引きも上げもしない。頭を傾けない（roll）。
4. **試し撮りを 3 秒行い、§5 の確認を通してから本番を撮る。** 通らなければ位置・照明・姿勢を直して撮り直す。
5. 本番は **20 秒（600 フレーム）**。開始と終了の各 1 秒は姿勢が落ち着かないので、その前後を含めて 22 秒回して先頭 600 フレームを使う。
6. 撮影中は話さない、まばたき以外の表情を作らない、髪を触らない。

### 4.3 何を変えるテイクか

| 目的 | 変えるもの | 変えないもの |
|---|---|---|
| セッション間ばらつきの本体（take04 / 05 / 06） | 撮影日だけ | 4.1 と 4.2 のすべて |
| pitch の感度（take07） | pitch だけを意図的に掃引（0 を跨がせる） | 距離・照明・尺、yaw / roll は可能な範囲で固定 |
| 照明の感度（take08） | 光源の位置または出力だけ | 距離・姿勢・尺 |
| 距離の感度（take09） | 被写体とカメラの距離だけ | 照明・姿勢・尺 |

**感度テイク（take07〜09）は、変えた量を記録すること。** 「どれだけ変えたか」が分からないと、表示値の動きを割り算できない。

**take07 は §4.2-2「視線を動かさない」と §4.2-3「顎を引きも上げもしない」を意図的に破るテイクである。** pitch を大きく・0 を跨いで動かすには、視線とあごの動きを止められない。yaw と roll は 4.2 の他の指示どおり可能な範囲で固定する。**§5 の確認表で pitch の中央値・標準偏差の目安が take07 だけ外れるのは想定内である。**（実測は `docs/symmetry-metric-measurements.md` §16.1）

## 5. 撮った後の確認

撮ったテイクが 4.1〜4.2 を満たしているかは、測定スクリプトで確かめる。

```bash
uv run python scripts/measure_session_variation.py --video take04.mov --section P --max-frames 600
```

出力の「共変量」表を、次の目安と突き合わせる。**この目安は §3 の実測ばらつきから引いた作業用の値であって、検証済みの受け入れ基準ではない。**

| 項目 | 目安 | 根拠 |
|---|---|---|
| 検出率 / 単一顔率 | どちらも 100% | take01〜03 が 3 本とも達成している |
| 顔 bbox 幅 | 0.17 ± 0.01（フレーム比） | take01 と take03 の帯。1280x720 では IOD 約 100 ± 6px |
| yaw / pitch / roll 中央値 | 各 \|1.0\|° 以内 | take01〜03 の全幅は 2.1〜4.5°。その 1/2 以下 |
| yaw / pitch / roll 標準偏差 | 各 0.5° 以内 | take02（0.327°）と take03（0.228°）が達成済み。take01（2.210°）は未達 |
| フレーム輝度 | 120〜130（0〜255） | take01 と take03 の帯。take02 の 140 は外れる |
| 顔領域の輝度 | 120〜140（0〜255） | take02 と take03 の帯 |
| 白飛び率（顔領域） | 0.2% 以内 | take02 は 0.000%、take03 は 0.928%、take01 は 3.259% |
| 黒つぶれ率（顔領域） | 0.2% 以内 | take01 は 0.000%、take02 は 0.017%、take03 は 1.742% |
| 読込フレーム | 600 | take03 は 585 で 15 枚不足 |

**白飛びと黒つぶれの両方を 0.2% 以内に収めたテイクは take01〜03 に 1 本も無い。** take01 は白飛び側、take03 は黒つぶれ側で外れている。ここが撮影で最も難しい項目である。

`--section P` だけなら注入測定を回さないので、1 本あたり 1 分程度で終わる。

## 6. 命名と保管

**顔の映像・座標をリポジトリへ入れない**（`CLAUDE.md` §5 のプライバシー不変条件）。

| 種別 | 名前 | 扱い |
|---|---|---|
| 映像 | `takeNN.mov` | `.gitignore` の `*.mov` が除外する。リポジトリ直下に置いてよいが commit しない |
| 測定 JSON | `take` で始まり `.json` で終わる名前（例 `take04-06_session.json`） | `.gitignore` の `take*.json` が除外する |
| 測定の要約 | `docs/symmetry-metric-measurements.md` | **統計量だけ。** 画像・座標・個人が特定できる情報は書かない |

測定スクリプトは JSON へ統計量しか書かない（画像も landmark 座標も書かない）。それでも出力先の名前は上の pattern に収めること。pattern から外れた名前は `.gitignore` に掛からない。

## 7. この手順が扱えていないこと

- **被写体 1 名。** 別の人を撮ると不変条件 1 に触れるため、本手順は同一人物の反復にしか使えない。
- **閾値は未検証。** §5 の目安は take01〜03 の散らばりから引いた作業用の値である。これを守ったテイクどうしで表示値がどれだけ揃うかは、take04 以降を撮って初めて分かる。
- **メイク・髪型・体調・時刻を統制していない。** これらは「その日の顔の違い」の側であり、本手順が固定するのは撮り方だけである。両者を分けるには、同じ日に 2 本撮る（撮り方だけが同じ）と別の日に撮る（両方が違う）の対比が要るが、本手順はその設計を含んでいない。
- **カメラは 1 台。** 別のカメラ・別の解像度での目安は測っていない。
- **`z`（推定奥行き）の撮影依存は本書の対象外。** 追跡ズーム経路での `z` スケールは `docs/symmetry-metric-measurements.md` §13 にある。
