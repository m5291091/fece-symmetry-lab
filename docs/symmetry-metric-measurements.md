## 0. 結論

**現行の 2D 指標は精度が足りないのではなく、部位によっては符号が逆に出る。**

| 部位に非対称を注入したとき、指標はどう動くか | 現行 2D | 3D |
|---|---|---|
| 輪郭 | +0.905 | +0.138 |
| 口 | +0.147 | +0.238 |
| **目** | **−0.008（無反応）** | +0.200 |
| **鼻** | **−0.472（逆向き）** | +0.057 |

**鼻を非対称にすると、現行の指標は「より対称になった」と報告する。** これは測定精度の問題ではなく、指標が誤っているということ。

3D object symmetry は全部位で正の応答を保つ唯一の方式だった。したがって **3D 化は選択肢ではなく必要条件**である。

## 2. 再現性 — 同じ顔を 2 回測る

| | take01 | take02 | 差 |
|---|---|---|---|
| **現行 2D** | 2.622mm | 4.592mm | **+75%** |
| **3D** | 1.157mm | 1.108mm | **−4%** |

**同一人物の同一の顔に対し、2D は 2 回の測定で 75% 違う値を返した。**

差の原因は姿勢。take02 は yaw が −3.38°（take01 は −0.82°）。`2·z·sinθ` の予測（yaw 3° で +0.032）と実測差（+0.031）がオーダーで一致する。

3D の値 1.1mm は文献の「対称な成人 1.52mm」と同じ手法・同じ土俵の量であり、物理的に妥当な範囲に着地している。2D の 2.6〜4.6mm は「臨床的に非対称」域で、これは姿勢汚染だった。

## 4. 姿勢依存 — 3 方式の比較（take01, 600 枚）

| 方式 | 平均 | ノイズ床 | 信号÷床 | \|yaw\|相関 | 鏡像差 | d ゲイン(口) |
|---|---|---|---|---|---|---|
| ① 現行 2D（正中線あてはめ） | 2.622mm | 1.673mm | 0.79x | **+0.854** | 0.834mm | 0.147 |
| ② 2D Procrustes | 1.921mm | 1.078mm | 1.23x | **+0.842** | 0.591mm | 0.132 |
| ③ 3D Procrustes | 1.157mm | 0.241mm | 5.52x | **+0.369** | 0.131mm | 0.238 |

**②は姿勢依存をまったく落とさない（+0.854 → +0.842）。**

理論どおりの結果である。yaw が生む偽ズレ `2·z·sinθ` は点ごとの奥行き `z` に比例する非剛体的なズレなので、2D の並進+回転では吸収できない。**姿勢問題を解いているのは Procrustes ではなく z である。**

②にも価値はある（ノイズ床 −36%、鏡像差 −29%）。しかし姿勢という主要因には無力で、ゲインはむしろ①を下回る。**「z を使わずに済ませる」道は無い。**

take02（yaw std 0.33° の静止テイク）では 2D +0.900、3D **+0.023**。姿勢の揺れがほぼ無い条件でも 2D は反応し、3D は無反応。

## 5. 感度 — 部位別ゲイン（take01, 領域変位場 σ=0.12 IOD, 5 フレーム）

「既知量の非対称を画像へ注入し、指標がどれだけ応答するか」。ゲイン 1.0 = 注入した分だけ正しく検出。

| 部位 | 注入点 | landmark 応答 | ① 現行2D | ② 2D-P | ③ 3D |
|---|---|---|---|---|---|
| 口 | 13 | 0.443 | +0.147 | +0.132 | **+0.238** |
| 目 | 26 | 0.672 | **−0.008** | −0.028 | **+0.200** |
| 輪郭 | 17 | 0.642 | +0.905 | +0.742 | **+0.138** |
| 鼻 | 7 | 0.255 | **−0.472** | −0.145 | **+0.057** |

### 現行 2D が壊れている 2 か所

**目のゲインが 0。** 眼アンカー 33/133/263/362 は §8.3 の正規化基準そのもの。目を非対称にしても正規化がそれを吸収するので、指標には出ない。`symmetry-metric-analysis.md` §5.3 で指摘した循環参照が、ゲイン 0 という形で確定した。**現行指標は目の左右差に対して構造的に盲目である。**

**鼻のゲインが負。** 鼻周辺の変位が正中線 27 点を引きずり、あてはめ直線が動く。基準線が動くと他部位の残差が変わり、総合値が下がりうる。§5.2 で指摘した「測っていない正中線点が全部を動かす」問題が、**符号を反転させるところまで来ている。**

### 検出器の抑制は部位で変わる

landmark 応答は 0.255〜0.672（最大÷最小 2.63 倍）。**「パイプラインのゲインは 0.42」と一般化できない。**

検出器は注入した幾何変化の 33〜75% しか登録しない。これは `symmetry-metric-analysis.md` §4.3 の「テンプレート抑制」仮説の実証だが、区分アフィン変形への応答低下と分離できていないため、上限値として読むべき。**この抑制は 2D でも 3D でも同じで、どちらの方式でも取り除けない天井である。**

### 3D の性質

全部位で正（0.057〜0.238）。ただし範囲は 4.2 倍あり、鼻が最も弱い（0.057）。

**3D と 2D の差は量ではなく質。** 2D は部位によって無反応・逆向きになるが、3D は常に正しい向きへ動く。

### 環境差（2026-08-09 追記）

輪郭の行だけ、別環境での再実行で **≤0.4% 動く**（landmark 応答 0.642 → 0.640、① 0.905 → 0.902、② 0.742 → 0.746）。同じ環境では 2 回とも安定するので run のジッタではなく、記録日（2026-08-08）とのライブラリまたは warp 経路の数値差である。**③ 3D の 0.138 は一致し、本節の結論は変わらない。** 他の 3 部位も一致する。この幅は追わない。本書の数値は環境間で 0.4% 程度の再現幅を持つものとして読むこと。

## 6. 検出器の左右バイアス（鏡像テスト）

同じ画像 `I` と左右反転した `mirror(I)` で d を測る。幾何学的に正しい検出器なら厳密に一致する（導出はスクリプト内）。

| 方式 | d 平均 | \|d(I) − d(mirror(I))\| 中央値 | d に占める割合 |
|---|---|---|---|
| 現行 2D | 2.622mm | 0.834mm | **31.8%** |
| 2D Procrustes | 1.921mm | 0.591mm | 30.8% |
| 3D | 1.157mm | 0.131mm | **11.3%** |

Procrustes がバイアスの 65% を吸収する。3D の残り 11.3% が、検出器由来の除去不能な床。

## 7. z は何を持っているか

Procrustes 重ね合わせの前後で、左右差を軸ごとに分解（take01）:

```
重ね合わせ前   x 2.267mm   y 0.601mm   z 1.792mm
重ね合わせ後   xy 1.111mm              z 0.404mm      （z/xy = 0.364）
```

恒等式 `d_3d² = xy² + z²` は誤差 0 で成立。

**生の z 左右差 1.792mm が、重ね合わせ後 0.404mm まで落ちる。** つまり生の z 非対称の 77% は剛体回転（＝姿勢）であって形ではない。

**z が完全なテンプレートなら、重ね合わせ前から z 非対称は小さいはずである。** 1.792mm あるということは、z は実際の奥行き情報を持っている。「実質 2.5D」ではない。

ただし残差比 0.364 は等方（約 0.71）より小さく、部位別では鼻 0.138 まで落ちる。z 方向の形状非対称は、面内より小さく出る傾向がある。

### z の再現性

| | z RMS 中央値 | 判定閾値 |
|---|---|---|
| take01 全体 | 0.0360 IOD (2.27mm) | 0.05 |
| take01（yaw ±0.5°） | 0.0155 IOD (0.978mm) | 0.05 |
| take02（静止） | **0.0087 IOD (0.549mm)** | 0.05 |

`symmetry-metric-level3.md` §4 で懸念した「z が悪すぎて 3D 化が割に合わない」は**否定された**。姿勢が固定なら z の素の再現性は 0.9% IOD 程度で、閾値の 1/5 以下。

## 8. 座標平均（対策10）— 効くが、姿勢オフセットには無力

| | 生値 | tau_app 12s | 実測SD比 ÷ 理論SD比 |
|---|---|---|---|
| take01 2D（姿勢が揺れた） | 2.622mm | 1.946mm | 6.7 |
| **take02 2D（姿勢が固定）** | **4.592mm** | **4.581mm** | 3.0 |
| take01 3D | 0.241mm（床） | 0.122mm（床） | 6.18 |

**take02 では座標平均しても平均値が動かない。** take01 では動いた。

違いは姿勢の性質である。

- take01 = yaw が**振れていた** → 平均で一部相殺される
- take02 = yaw が**ずれたまま固定** → 何回平均しても消えない

**座標平均が消せるのは姿勢の「揺れ」だけで、「オフセット」は消せない。** 少し横を向いて座る人はオフセットを持つ。これが現実の使われ方である。

また実測 SD 比は理論の 3〜6.7 倍で、**Procrustes が姿勢を消した後（3D）でも 6.18 倍**。30fps の隣接フレーム間に、姿勢以外の強い時間相関が残っている（出所は未分離）。

座標平均は補助手段であって、主対策にはならない。

## 9. 別件 — 対称化ビジュアライゼーションの三角形が裏返る（FR-034/FR-035）

診断中に、出荷済み機能の欠陥が確認された。**指標の話とは独立。**

`application/symmetrization.py` の手順（`symmetrize_landmarks` → `build_warp_mesh` → `OpenCvPiecewiseWarper._triangles`）を実写 60 枚でなぞり、三角形の符号付き面積が source と target で符号を変えるかを数えた結果:

| | |
|---|---|
| 1 フレームの三角形 | 949 |
| 裏返る三角形 | 中央値 7 / 最大 12 / 60 枚で計 421 |
| 裏返りの位置 | 全件が顔ランドマーク領域の内側（外周アンカーは 0 件） |
| 対称化変位の最大 | 2.37mm（中央値）〜3.56mm |
| 変位ガード | 15.75mm ← **一度も働かない** |

### 原因

変位ガードは「1 点の絶対変位」の上限。裏返りは「隣接点の相対変位が点間隔を超えるか」で決まる。**前者は後者を含意しない。**

対称化変位は各ペアの実測ズレの半分で決まるので、隣り合う landmark が別々のズレを持てば相対変位が生じる。密な領域では点間隔が数 px しかなく、1.2〜5.4px の相対変位で符号が反転する。

### 退化判定が通してしまう条件

`is_degenerate_triangle` は `triangle_area`（絶対値）が `MIN_TRIANGLE_AREA_PX = 1e-3 px²` 未満かだけを見る。**source と target の向きを比較していない。**

裏返りは符号を反転させるが |面積| を縮めないので、判定を素通りする。

```
通過条件 = sign(area_source) ≠ sign(area_target) かつ 両方の |area| ≥ 1e-3 px²
```

実測 421 件すべてが通過。最小の面積でも 0.013px²（閾値の 13 倍）、中央値 6.1px²。**261/421 件は両側とも 1px² 超**で、細長い縁ではない本物の反転。

### 現状の視覚的影響と、仕様上の位置づけ

裏返る三角形は面積中央値 6〜19px²、最大 43px²、1 枚あたり合計 10²px² 程度。**現状の影響は小さい。ただし機構は実在し、非対称が大きい被写体ほど拡大する。**

`requirement.md §8.6.4` / `FR-035` / `AC-SYMM-02` / `testbox.md` の破綻防止は「変位ガード」「退化三角形（面積が下限未満）」「座標解決不能」の 3 つだけで、**向きの反転に一切触れていない。** ADR にも該当項目なし。

`build_warp_mesh` の docstring は「その先では区分写像が自分自身へ折り重なり」と書いており、**折り重なりがガード超過時のみ起きるという含意になっているが、実測と一致しない。**

意図的な設計判断ではなく、仕様の想定外と読むのが妥当。

### 対処（2026-08-08 実施）

`requirement.md §8.6.4` の破綻防止へ「向きの反転」を第 4 条件として追加し、
`domain/warp_mesh.py` に `signed_triangle_area` / `is_orientation_flipped` を、
`adapters/imaging/piecewise_warp.py` に読み飛ばし判定を入れた。
`is_degenerate_triangle` は拡張していない（「面積が小さすぎる」と「向きが反転している」は
別の破綻であるため）。変位ガードの閾値は変更していない。

**重要な区別 — 裏返り自体は無くなっていない。**

```
修正前   裏返った三角形が、逆向きのアフィンで画素を転送する  ← 画像が壊れる
修正後   裏返った三角形は読み飛ばされ、元の画素が残る        ← 壊れないが、変形もされない
```

**1 フレームあたり中央値 7 個という裏返りの発生数は変わらない。** これは対称化変位場が
メッシュの点間隔に対して滑らかでないという性質であって、ワーパー側の問題ではないため。

したがって次の制約が残る。

- 対称化画像には、変形されない小領域が毎フレーム数個含まれる（面積中央値 6〜19px²、
  1 枚あたり合計 10²px² 程度）
- **非対称が大きい被写体ほど読み飛ばしが増える。** つまり対称化が最も意味を持つ相手ほど、
  対称化されない領域が広がる
- 読み飛ばし件数は観測されない（`PiecewiseWarper` port は画像だけを返す契約で、
  既存の退化・座標解決不能の読み飛ばしも無言。それに揃えた）

根本的な対処は変位場の正則化（平滑化、またはメッシュの細分）だが、FR-034 の出力そのものを
変えるため別課題とする。

**未検証**: 実写での再測定は未実施（素材を保管しない制約による）。確認する場合、見るべきは
「メッシュ上の裏返りが 421 → 0」ではなく **「転送された裏返りが 421 → 0、メッシュ上の裏返り数は不変」** である。

## 10. 未解決

- **被写体 1 名**。部位別ゲインの値が個人差でどう動くかは未検証。他人の顔の撮影・保管は不変条件 1 に触れるため、部位依存で代替した
- **検出器の抑制（landmark 応答 0.255〜0.672）の内訳**。「合成レンダリング学習によるテンプレート抑制」と「区分アフィン変形という不自然な入力への応答低下」を分離できていない。したがって 0.26〜0.67 は真の抑制の**上限**
- **領域変位場の σ=0.12 IOD** は設計判断。σ 依存性は未測定
- **セクション I の判定は yaw の動く範囲に依存**（600 枚で ② の位置 +0.18、120 枚で +0.40）。他の撮影で「② の姿勢依存が落ちない」が再現するかは未確認
- **座標平均の残存時間相関**（実測 ÷ 理論 = 6.18）の出所。被写体の微動か z のドリフトか未分離
- **再現性 ≠ 誤差**。本書のノイズ床はすべて再現性であり、正解に対する誤差の下限にしかならない

## 12. 表示スケールの実効分解能

§1〜§11 は `d`（両眼間距離比）を測った。本節は同じ測定を `requirement.md §8.6.3` の表示式へ通したときに、**利用者が読む数字がどう振る舞うか**を測る。

```text
symmetry_percent = clamp(100 × (1 - d), 0, 100)
```

### 12.0 単位 — pt は IPD の仮定に依存しない

### 13.0 何を測るか

フレームごとに、直叩きの `z_direct` と zoom 経路の `z_zoom` を**全 478 点まとめて** 1 本の直線へ当てる。

```text
z_zoom ≈ α · z_direct + β
```

`z` の原点は頭部中心付近の相対量なので、点ごとの比には意味がない（分母が 0 を跨ぐ）。したがって 1 点ずつではなく 1 フレームにつき 1 組の (α, β) を出す。単位はフレーム比で、`β(IOD)` は 3D 両眼間距離で割った値である。

`remap_depths` が正しければ α = 1、β = 0 になる。

### 13.8 この測定で言えないこと

- **被写体 1 名・3 テイク・1 台のカメラ（1280x720）。** 追跡中の窓幅は 0.24〜0.34 に収まっている（既定 `margin_ratio` = 0.6 なので、顔 bbox の幅にして 0.15〜0.21）。これより極端に大きい / 小さい顔での α は測っていない
- **窓幅 0.20 未満は測っていない。** `min_window_size` の既定は 0.18 だが、顔 bbox がそれを下回る条件（もっと遠い被写体）は本測定の素材に無い
- **窓の高さは独立に掃引していない。** `min_window_size` は幅と高さの両方に効くので、窓高が 0.327 を超える行では幅と高さが同時に動いている。`remap_depths` が掛けるのは幅だけなので主結論は幅で読めるが、「高さだけを変えたときの α」は測っていない
- **α の estimator は検出そのものの変化を含む。** 対照 x / y はその大きさを測るために置いたものであって、α から差し引ける較正値ではない
- **§13.6 の欠落率はアプリの実測ではない。** 明るさ調整（FR-028）も品質ゲートも通していない素の経路での値である。アプリは自動調整で `margin_ratio` と `target_px` を動かすので、窓幅の帯も欠落率も変わりうる
- **`--stride 6` は解析周期の近似である。** アプリの `analysis_interval_ms` は 125/200/333ms から自動選択される（FR-030）ので、5Hz は候補の 1 つにすぎない
- 3D 側は `requirement.md §8.6.5` のとおり**表示・EMA・エクスポートへ未接続**である。本節の pt 表記は §12 と同じく「もし現行の表示式へ載せたら」の測定である

### 15.0 何を測るか

1 本のテイクの中だけで、フレームごとの表示値を姿勢角へ回帰する。

```text
表示値(pt) = a + b × 姿勢角(度)
```

`b` が感度で、単位は pt / 度。1pt = 0.01 IOD なので IPD の仮定に依存しない（§12.0）。

- **符号付きの角度と |角度| の両方**で出す。§8.5.1 の剛体不変性は数学的に厳密なので、真の landmark が剛体で回っただけなら `d_3d` は動かない。符号付きで単調なら不変性の側、|角度| で動くなら検出器の誤差の側を疑う材料になる
- **95% 区間**は、ラグ 1 の自己相関で実効枚数を補正した標準誤差（Bartlett / Quenouille の近似）× 1.96。30Hz の隣接フレームは強く相関するので、素の n をそのまま使うと区間が実際よりずっと狭く出る。**近似であって、被覆率を主張できるものではない**
- **第 1 階差**（隣り合うフレームの差どうしの回帰）も併記する。20 秒のあいだ表示値と姿勢が同じ向きにゆっくり漂うだけでも水準の相関は立つので、その分離のために置いた。ただし階差はノイズを増幅するので傾きは 0 側へ引っ張られる

### 15.6 数値から直接言えること

- **検算（3D・pitch・yaw 層別）は 0.0680 pt/度 × 4.529° = 0.308pt。実測の全幅は 0.273pt で、比は 1.13。** 依頼の目安（0.1〜0.6pt）の中に入っている。テイクごとの傾きで作った予測の範囲は 0.264〜0.580pt で、**下端が実測とほぼ同じ、上端が実測の 2.1 倍**である
- **層別前は 3 軸が同じ桁で並び、検算は pitch を選び出さない。** 全フレームでの予測は pitch 0.183 / yaw 0.296 / roll 0.140pt（比 0.67 / 1.08 / 0.51）。**yaw で 1.08 が出る以上、「0.27pt に届く」だけでは pitch を主犯とは言えない**
- **yaw を止めると pitch と roll が分かれる。** 予測は pitch 0.308pt（1.13x）に対し roll 0.075pt（0.27x）。roll は層別前の 0.140 から下がり、pitch は 0.183 から上がる
- **3D の pitch 感度は、全フレームでは 3 本中 1 本でしか区間が 0 を外れない。** 外れたのは take03（−0.131 pt/度）で、**pitch がいちばん大きく動いた take01（標準偏差 1.864°、p95−p05 6.286°）は −0.020 pt/度 で区間が 0 を跨ぐ。** 変動幅がいちばん大きいテイクで、いちばん小さい傾きが出ている
- **yaw を止めると 3 本の傾きがそろう。** −0.068 / −0.058 / −0.128 pt/度（層別前は −0.020 / −0.041 / −0.131）。3 本の幅は 0.112 → 0.070 pt/度 へ狭まり、3 本中 2 本で区間が 0 を外れる。take01 の変化がいちばん大きく、−0.020（0 を跨ぐ）→ −0.068（跨がない）である
- **3D は符号付き pitch で符号がそろい、現行 2D は |pitch| でそろう。** 層別後の 3D は 3 本とも負（−0.068 / −0.058 / −0.128 pt/度）。現行 2D は符号付きで +0.269 / −0.023 / −0.231 と割れるが、|pitch| に直すと take01 +0.269 と take03 +0.231 が同じ向きになる（この 2 本は区間が 0 を外れ、take02 はどちらの取り方でも跨ぐ）。**ただし §15.2 のとおり 1 本の中では両者を区別できないので、これは 3 本を並べて初めて言える話であり、n=3 である**
- **残差（3D・yaw 層別の傾き）は +0.067 / −0.068 / +0.002pt。** take03 は 0.002pt まで合うが、**take01 と take02 の並び（実測 98.280 > 98.249）は再現できていない**（予測は 98.213 < 98.318 で逆順）。残差の幅 0.135pt は実測の全幅 0.273pt の 49% で、**約半分が説明されずに残る**
- **現行 2D のテイク間差は pitch で説明が付かない。** 予測 0.102pt（yaw 層別）に対し実測 5.775pt で 0.018x。§14.5 のとおり 2D で外れているのは yaw が −3.401° にある take02 であり、その構造が本節でも保たれている
- **第 1 階差では 3D の pitch 応答が見えなくなる。** r(Δ) は −0.093〜+0.212、傾きΔ は −0.036〜+0.091 pt/度。ただし階差はノイズを増幅して傾きを 0 側へ引っ張るので、**「消えた」ことは「無い」ことの証明にならない**
- **測定系は §4 と §14 を再現している**（§15.1）。|yaw| 相関 4 件が 3 桁一致し、pitch と表示値の中央値も一致する。**「2D で応答が出ることの確認」は、pitch ではなく yaw で取れている**（take01 −1.063 / take02 +1.982、いずれも区間が 0 を外れる）

### 15.7 この測定で言えないこと

- **pitch と 顔領域の黒つぶれ（§14.5 のもう 1 つの候補）を分けていない。** 本節の説明変数は姿勢だけである。within-take では照明がほぼ動いていないので、黒つぶれの寄与はそもそも測れない。**この 2 つを分けるには照明だけを変えたテイクが要る**
- **1 本の中で pitch を意図的に振ったテイクが無い。** 3 本とも「たまたま動いた分」であり、p95−p05 は take01 で 6.286°、take02 / take03 では 1.3〜1.4° しかない。掃引テイク（take07）があれば同じ測定が桁違いに強くなる
- **3 本とも pitch が 0 を跨がない。** 符号付きと |pitch| の区別は within-take では原理的に付かない（§15.2）
- **within-take の傾きを between-take へ外挿している。** §15.5 の検算は「1 本の中で pitch が 1° 動いたときの効き」と「別のセッションで pitch が 1° 違うときの効き」が同じだと仮定している。**この仮定自体は測っていない**
- **水準の回帰は共通のドリフトで立ちうる。** 20 秒のあいだ表示値と姿勢が同じ向きに漂うだけで相関は出る。第 1 階差を併記したのはその分離のためだが、階差はノイズで薄まる。**どちらも決定打にならない**
- **区間は近似である。** 自己相関の補正を掛けているが被覆率を主張できるものではない。「0 を跨ぐか」を目安として読むこと
- **pitch そのものが同じ検出器の推定値である。** §8.2.1 の変換行列から出した値であり、真の頭部姿勢ではない。ADR 0002 の実写確認は未実施なので、姿勢の推定誤差と `d_3d` の誤差が共通の原因を持つ可能性を排除していない
- **`d_3d` が動いた仕組みを特定していない。** 測ったのは「pitch と表示値が一緒に動くか」であって、動いた経路（`z` の推定誤差か、別の何か）ではない
- **テイクは 3 本。** 検算の分母（§14.4 の 0.273pt）も分子の傾きの中央値も、標本 3 本の量である
- 3D 側は `requirement.md §8.6.5` のとおり**表示・EMA・エクスポートへ未接続**である。本節の pt 表記は §12〜§14 と同じく「もし現行の表示式へ載せたら」の測定である

### 16.0 何を測るか

§15 のセクション T/Y/X は「表示値 = a + b・姿勢角」という直線を 1 本当てはめ、傾き b を 1 個だけ出す。take01〜03 では pitch が 1.3〜6.3° の範囲でしか動いておらず、§6.7 はその傾き（0.068 pt/度、yaw 層別・3 本の中央値）を姿勢ゲート 30° 幅へ 24 倍外挿して 2.04pt という見積りを作った。この外挿が過大かどうかは、傾き 1 個からは分からない。

本節は take07（pitch 掃引）で 4 つを出す。

1. **S-1** pitch をビンへ切り、表示値の中央値と四分位を並べる（形を目で見る）
2. **S-2** 符号付き線形 / |pitch| 線形 / 折れ線（pitch=0 で連続な hinge）の 3 モデルを当てはめて比べる
3. **S-3** 姿勢ゲート内（|pitch| <= `pitch_inner_deg`、既定 15.0°）に絞って S-2 をやり直す —— 外挿ではなく直接測る
4. **S-4** IOD・黒つぶれ率・輝度が pitch と一緒に動いていないかを見る —— 掃引でだけ顕在化する交絡

### 16.6 数値から直接言えること

- **ビン別の中央値は単調ではない**（§16.2）。3D は −30〜−25° 帯から −25〜−20° 帯へ一度下がり、2D は −20〜−15° 帯に谷を持つ。傾き 1 個の直線では、この凹凸は表現できない
- **3D 全域では 3 モデルの R² が横並び（0.2941 / 0.3077 / 0.3105）で、R² だけからは形を判定できない。** 折れ線の b_neg（+0.0351）と b_pos（−0.0175）の符号が逆であることから |pitch| 型（劣化）と読める
- **姿勢ゲート内に絞ると折れ線の符号が反転する。** 全域・yaw 層別では b_neg と b_pos が逆符号（|pitch| 型）だが、ゲート内では b_neg（+0.0059）と b_pos（+0.0076）が同符号（符号付き型）になる。**「形」は測る範囲によって変わる数値であり、全域の 1 回の当てはめだけで確定させられる性質のものではない**
- **ゲート内の実測傾き（0.0066 pt/度）は、§15 の外挿（0.0680 pt/度）の約 1/10 である。** 姿勢ゲート 30° 幅への換算では、外挿の 2.04pt に対しゲート内実測は 0.20pt、yaw 層別実測は 0.70pt（§16.5）
- **IOD と符号付き pitch は全域で r = +0.958、ゲート内でも r = +0.849 と強く相関する。** 全域の重回帰では pitch 係数 +0.0167 pt/度・IOD 係数 +0.0616 pt/px で大きさが同程度に割れるが、ゲート内では pitch 係数 +0.0071 pt/度（単回帰の +0.0066 とほぼ同じ）・IOD 係数 −0.0037 pt/px（単回帰の 1/2 未満）になり、ゲート内では pitch 係数が IOD の有無に左右されにくい
- **IOD の 5 分位帯ごとの pitch 傾きは一様ではない。** 77.0〜81.9px 帯で最大（+0.0764）、86.2〜88.4px 帯で最小かつ区間が 0 を跨ぐ（+0.0027、`*0`）
- **顔領域の黒つぶれ率（face_clip_low）は符号付き pitch と r = +0.466、白飛び率（face_clip_high）は r = −0.402 で、いずれも pitch と一緒に動いている**
- **現行 2D は「形」の読みが 3D よりさらに揺れる。** 全域・ゲート内は |pitch| 型、yaw 層別だけ符号付き型になる

### 16.7 この測定で言えないこと

- **take07 は 1 セッションである。** §6.7 が心配していたのは「別の日に少し違う頭の角度で座る」という**静的オフセット**（take01〜03 の 2.809 / 1.273 / −1.720°）で、本節が測ったのは 1 本の中で首を振り続けた応答である。同じ量ではない。§15.7 の「within-take の傾きを between-take へ外挿している」という宿題は向きが変わっただけで残る
- **ゲート内のフレームはすべて掃引の通過中である。** 静止時と比べてモーションブラーと検出器の時間的挙動が違う可能性を、本節は排除していない
- **IOD と pitch は全域で r = +0.958 あり、分離できていない。** ゲート内（r = +0.849）では重回帰で pitch 係数がほとんど動かないので分離できるが、全域では pitch と IOD の寄与がほぼ同じ大きさに割れる
- **黒つぶれ率が pitch と一緒に動く。** §15.7 は「within-take では照明が動かないので黒つぶれの寄与は測れない」としていたが、頭を 50° 振ると顔への光の当たり方が変わる。§14.5 で分けられなかった 2 候補は within-take でも絡んだまま
- **被写体 1 名・take07 は 1 本。** 形が個人差を持つかは測っていない
- **本節も、within-take の傾きが between-take の効きと同じという仮定を検証していない**（§15.7 の宿題そのもの）。ゲート内実測が §15 外挿の 1/10 だったことは、外挿が過大だった可能性を示すが、静的オフセットに対する感度を測ったわけではない
