## なぜ別の版を起こしたか

`symmetry-2d/2.0.0` は、部位によって応答の**符号が逆**になる。較正で直る種類の問題ではない
（実測は `docs/symmetry-metric-measurements.md` §5、要件側の記録は `requirement.md` §8.6.6）。

| 部位 | `symmetry-2d/2.0.0` | `symmetry-3d/1.0.0` |
|---|---:|---:|
| 輪郭 | +0.905 | +0.138 |
| 口 | +0.147 | +0.238 |
| 目 | **−0.008** | +0.200 |
| 鼻 | **−0.472** | +0.057 |

原因は 2 つの構造にある。

- **正中線あてはめ**（§8.4）— 測っていない正中点 27 点の変位があてはめ直線を動かし、測っている
  全部位の残差を動かす。鼻を非対称にすると総合値が下がりうる。
- **眼アンカーの循環参照**（§8.3）— 33 / 133 / 263 / 362 は正規化基準そのものなので、目の
  非対称は正規化に吸収されて距離へ現れない。

object symmetry 解析は「どの平面で折るか」を先に決めないので、どちらの経路も持たない。

## 距離の定義

対応ペア 63 組（126 点）の 3D 座標を鏡映し、ペア表そのものである置換 `σ` で左右の名前を
入れ替え、元の配置へ**並進と回転だけで** Procrustes 重ね合わせる。残差の RMS が `d_3d`。

```text
X    = 対応ペア 126 点の 3D 座標
M(X) = σ( mirror_x(X) )
d_3d = sqrt( mean_i || X_i - (M(X)·R + t)_i ||² )      R は回転、スケール自由度なし
```

`X` を剛体で動かすと `M(X)` も同じだけ動くので、`d_3d` は頭部の並進・回転（yaw / pitch /
roll のすべて）に対して不変である。

**正中線 27 点は使わない。** bundle には同じ `landmark_map_version` を共有する都合で
`midline_indices` が残っているが、この指標は読まない。

## 正規化スケール — 唯一の設計判断

`d_3d` は**3 次元で測った**両眼アンカー間距離を 1.0 とする。§8.3 の 2D 投影距離ではない。

重ね合わせが並進と回転を吸収するので、正規化のうち値へ効くのは**スケールだけ**である。原点の
取り方と面内回転は 3D の剛体変換であり、残差を変えない。

2D 投影距離を使うと、yaw が `θ` のとき両眼間が `cos θ` 倍に縮むぶん `d_3d` が `1/cos θ` 倍に
膨らみ、**剛体不変性で追い出した姿勢依存が正規化という裏口から戻る。** `θ = 0` では両者が
一致するため、正面の合成顔だけを見ていると発見できない。実測で確認済み
（`docs/symmetry-metric-measurements.md` §4）。

`z` は MediaPipe の推定奥行きであり、`x` と同じ係数（画像の**幅**）で画素相当へ戻す（§8.1.1）。
3 軸の単位が揃っていないと、Procrustes の回転が軸ごとに違う長さを混ぜる。

## 出力

| 出力 | 位置づけ |
|---|---|
| `d_3d` | 総合値 |
| `d_3d,p`（部位別） | **並列の診断値**。総合値へ寄与しない |
| xy 成分 / z 成分 | 同上。`d_3d² = xy² + z²` が恒等的に成立する |

部位別は**部位ごとに重ね合わせ直すのではなく、全 126 点で 1 回だけ重ね合わせた残差を部位ごとに
読む**。理由は §8.6.5 に 4 点記録した（要約すれば、部位ごとに走らせると部位間で比較できない量に
なり、3D 剛体の 6 自由度がペア数の少ない部位ほど残差を吸収し、恒等式も壊れる）。

全部位が使用可能なとき `d_3d² = Σ_p m_p·d_3d,p² / Σ_p m_p` が恒等的に成り立つ。`m_p` は版管理
された対応マップから一意に決まる点数であって設定値ではない。

`exp` 変換、感度係数 `k_p`、部位重み `w_p` は持たない。`symmetry-2d` v2.0.0 で廃止した自由
パラメータを、新しい bundle で復活させていない。

## 欠測

- `z` が欠測のフレームでは `d_3d` を算出せず欠測とする。0 で埋めない。`symmetry-2d/2.0.0` の
  出力は影響を受けない。
- 使用可能な対応ペアが 30 組（= `Σ_p min_pairs_p`）を下回る場合、重ね合わせ自体を行わず、
  総合値・部位別値・分解のすべてを欠測とする。2D と違い、部位別値が総合値と同じ 1 回の
  重ね合わせを共有するためである。

## 値の解釈

0 が下限で上限はない。小さいほど、鏡映してペア名を入れ替えた配置が元の配置へよく重なることだけ
を意味する。母集団内順位、正常範囲、美的品質、人物間の差としては解釈できない。

参考として `Prog Orthod 2015`（3D スキャン＋鏡像重ね合わせ、n=28/27）は「対称と判定された成人
1.52mm / 非対称と判定された成人 2.85mm」を報告している。同じ手法・同じ土俵の量だが、**本指標の
入力は 3D スキャンではなく単眼推定の `z`** であり、値を直接あてはめて個人を分類してはならない。

## この版の適用範囲

**主指標として、EMA・`AnalysisOutcome`・表示・エクスポート・`SessionRecorder` のすべてへ
接続している**（FR-036）。エクスポートスキーマ `4.0.0` は本 bundle の出力を `distance3d_*`
列（部位別・全体・平滑値・部位等重み `s_3d`）として記録し、`metric_version` は
`symmetry-3d/1.0.0` を指す。`symmetry-2d/2.0.0` は表示から外れ、エクスポートには
`distance_*_raw` と `metric_version_2d` として診断目的で残る。

## 未取得の証跡

- **被写体 1 名**。部位別ゲイン（+0.057〜+0.238）の個人差は未検証（OD-09）。
- **追跡ズーム下の `z` は未実測。** `TrackingZoomLandmarker.remap_depths` は「窓の幅比を掛ける
  だけ」と定義したが、実測はすべて landmarker 直叩きで行っており、この写像を通していない。
  倍率誤差が窓の大きさに応じて変動する場合、3D 化で消したノイズがリアルタイム経路で戻る。
  並走評価はこの経路を通さないので W2 の障害にはならないが、表示へ接続する前に潰すこと。
- **検出器の抑制**（注入した幾何変化のうち landmark が登録するのは 33〜75%）は 2D でも 3D でも
  同じで、方式に依存しない天井である。3D 化はこの天井を上げるものではなく、天井の下で指標が
  正しい向きへ動くようにするもの。
- 分布の参考統計（`d_3d` の件数・四分位・同一人物の再撮影差）は未取得。
