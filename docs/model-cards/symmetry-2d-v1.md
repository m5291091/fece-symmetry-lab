## 現在の係数

`contour=30.0`、`eyes=40.0`、`nose=40.0`、`mouth=35.0` は暫定値であり、
`sensitivity_frozen: false` とする。固定評価セットによる分布・感度・再撮影差の結果が
存在しないため、母集団内順位、正常範囲、美的品質、人物間の差として解釈できない。

## 固定評価プロトコル

1. 本人の明示同意がある成人の入力だけを使い、画像・映像・landmarkを保存しない。
2. 同一人物について、端末・距離・照明を固定した独立再撮影を2回以上行う。
3. 各撮影で品質ゲートを通った連続フレームをCSVまたはJSONへ明示保存する。
4. `metric_version` と `config_fingerprint` が一致するレコードだけを同じ評価へ含める。
5. 部位別 `distance_*_raw` の件数、最小値、四分位、中央値、最大値を報告する。
6. 候補 `k_p` ごとにスコア分布、局所摂動への単調感度、同一人物の再撮影差を比較する。
7. 評価セットの構成、除外理由、撮影条件、採用根拠をこのカードへ追記し、
   `metric_version` を更新したうえでのみ `sensitivity_frozen: true` にする。

## エクスポート契約

スキーマ `1.1.0` は校正用の正規化RMSを追加した互換拡張である。画像、映像、
landmark座標、元ファイル名、人物名は含めない。派生数値も匿名とは限らないため、
利用者の明示操作でのみ保存し、共有先と保持期間を管理する。
