## v1.0.0 からの変更

`score_p = clamp(100 × exp(-k_p × d_p), 0, 100)` と `overall = Σ(w_p × score_p)` を廃止した。

感度係数 `k_p`（contour=30.0、eyes=40.0、nose=40.0、mouth=35.0）は固定評価セットで凍結
されないままの暫定値であり、部位重み `w_p`（各 0.25）には経験的根拠がなかった。この 2 つの
恣意的なパラメータが 0〜100 という「点数」の見え方を決めていたため、両方を削除し、
測定値そのものを出力する方式へ置き換えた。

- **部位別**: 正規化 RMS 距離 `d_p` をそのまま出力する。単位は両眼 anchor 間距離（§8.3 が
  1.0 に正規化する）に対する比であり、UI は百分率で表示する。
- **全体**: 4 部位の対応ペア（contour 17・eyes 26・nose 7・mouth 13、合計 63 組）を 1 つの
  集合へプールし、正中線で 1 回だけ折りたたんだ RMS 距離とする。各対応点がちょうど 1 票
  ずつ数えられ、部位重みは存在しない。
- 全部位が使用可能な場合に限り `d_all = sqrt(Σ_p n_p·d_p² / Σ_p n_p)` が恒等的に成り立つが、
  `n_p` は版管理された対応マップから一意に決まる件数であって設定値ではない。部位が欠測
  しても `d_all` は残りのペアだけで定義できるため、プール式を primitive とする。
- 部位別と全体は並列の独立出力であり、部位別は全体の計算へ寄与しない。
- 欠測: 部位は `min_pairs`（8/13/3/6）未満で欠測。全体は使用可能ペアが 30 組
  （= `Σ_p min_pairs_p`）未満で欠測。いずれも 0 へ置換しない。

正中線の推定（`midline_indices` による TLS フィット）は v1.0.0 から変更していない。対応
マップ自体も同一であり、変わったのは距離から出力値を作る段だけである。

## 値の解釈

0 が下限で上限はない。小さいほど対応点のズレが小さいことだけを意味する。母集団内順位、
正常範囲、美的品質、人物間の差としては解釈できない。検出誤差・姿勢・撮影条件で値が動く
ため、同一人物・同一環境内の相対変化だけを参照する。

## 対称化ビジュアライゼーション（`symmetry-2d/2.0.0` に同梱）

対応ペア `(l, r)` について `mid_l = (left_l + mirror(right_r)) / 2`、`mid_r = mirror(mid_l)`。
正中点は `(p + mirror(p)) / 2`（正中線への直交射影）。対応ペアが定義されていない点は
対称化対象外として実座標のまま残す。

対称化点と実測点の距離は `||left_i - mirror(right_i)||` の 1/2 であり、新しい指標では
なく上記距離の別表現である。対称化した顔を「理想」「正解」「補正後」として提示しない。

## 参考統計プロトコル（リリース条件ではない）

較正対象の係数が無くなったため、以下は分布把握のための任意調査であり、
リリースのゲートではない。

1. 本人の明示同意がある成人の入力だけを使い、画像・映像・landmarkを保存しない。
2. 同一人物について、端末・距離・照明を固定した独立再撮影を2回以上行う。
3. 各撮影で品質ゲートを通った連続フレームを §9.2 の内部記録として残す（FR-017 の
   CSV / JSON は 2026-08-16 に撤回済みで、書き出せるのは FR-042 の HTML レポートだけである）。
4. `metric_version` と `config_fingerprint` が一致するレコードだけを同じ評価へ含める。
5. `distance_*_raw` と `distance_overall_raw` の件数、最小値、四分位、中央値、最大値、
   および同一人物の再撮影差を報告する。
