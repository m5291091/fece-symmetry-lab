# Model card — age-gate/1.0.0（動作点 revision 3）

## 用途

顔の幾何特徴から **18〜75 歳の範囲内かどうかだけ**を判定し、アプリが参考年齢
（FR-022）を表示してよいかを決める。**年齢そのものは推定しない。**

## 適用範囲（重要）

**この動作点は「乳幼児ゲート」である。** 0-5 歳は 89.5% 弾けるが、6-11 歳は 33.1%、
12-14 歳は 19.7%、15-17 歳は 4.3%、76 歳以上は 9.6% しか弾けない。

- **学童期以上の未成年ゲートとして使えない。**
- **上限側（76 歳以上）のゲートとして使えない。** 幾何特徴だけでは皮膚の質感を
  見られないためで、設計上の限界である。
- 15〜17 歳と 18〜20 歳は予測確率の分布が重なっており、**原理的に分離できない。**

このゲートを通ったことは「18〜75 歳である」ことを意味しない。意味するのは
「乳幼児の顔の幾何とは明らかに違う」ことだけである。

## 使ってはならない用途

年齢認証、本人確認、未成年判定、入場制限、採用、保険、教育、監視、人物間比較。

判定結果を利用者へ属性として提示してはならない（「18 歳未満と判定されました」
「未成年です」等）。表示してよいのは「この画像では参考年齢を表示できません」までである。

## 入力

- `features`: float32 `[N, 41]`。順序は `configs/age-gate-v1.json` の `feature_names`。
- 前段の条件: 単一顔であること、姿勢ゲート（|yaw|<=15°, |pitch|<=15°, |roll|<=25°）を通っていること。

## 出力

- `probabilities[:, 1]` = 範囲内である確率。
- `probabilities[:, 1] > 0.20` のとき「範囲内」。それ以外は「範囲外」。
- **`label` 出力は使わない**（静的 shape `[1]` のため）。必ず `probabilities` を読む。

## 閾値の決め方

**目標**: 「明らかに範囲外と言える顔だけを弾く」。範囲内を誤って弾く率が 2% を
下回る動作点のうち、最も高い閾値を選ぶ。

**なぜこれ以上上げないか。** 6〜11 歳の予測確率は中央値 0.419・p90 0.843 で成人と
重なっており、この帯を取りに行くと必ず成人を巻き込む。rev2 の 0.6782 は rev3 の
0.20 に比べ、成人の損失を 1.1% → 15.2% と **14.1 ポイント増やして**、0-5 歳の検出を
89.5% → 98.8% と **9.3 ポイントしか増やさない**。増分の大半は 6-11 歳（+40.3pt）と
15-17 歳（+39.8pt）で、後者は 18〜20 歳と原理的に分離できない帯である。

**なぜこれ以上下げないか。** 0.10 では 0-5 歳の検出が 84.6% まで落ち、乳幼児ゲート
としての実効が薄れる。

### 群ごとの子ども検出率（test, n>=15）

この動作点で意味を持つのは「子どもを群ごとに等しく弾けているか」である。

| 次元 | 群 | 0-5 歳 | n | 0-11 歳 | n |
|---|---|---:|---:|---:|---:|
| race | Asian | 89.9% | 149 | 85.6% | 160 |
| race | Black | 81.2% | 16 | 51.9% | 27 |
| race | Indian | 92.2% | 64 | 78.2% | 87 |
| race | Others | 88.1% | 67 | 82.5% | 80 |
| race | White | 89.4% | 113 | 65.5% | 194 |
| gender | female | 89.9% | 199 | 74.5% | 271 |
| gender | male | 89.0% | 210 | 75.8% | 277 |

0-5 歳では 81.2〜92.2% に収まり、性別ではほぼ差がない。0-11 歳での幅（51.9〜85.6%）は、
群内での 0-5 歳と 6-11 歳の構成比の違いを含む。

### 誤って弾く側の群差（test, n>=30）

範囲内を誤って弾く率は **0.005〜0.019** に収まる（rev2 では 0.126〜0.189 だった）。
性別では female 0.013 / male 0.010 で、rev2 にあった差（0.184 / 0.126）は解消している。
完全な表は `age-gate-v1-evaluation.json` の `group_error_report` を参照。

## 限界

- **乳幼児ゲートである。** 学童期以上の未成年はほとんど弾けない。
- **76 歳以上は判定できない。** 上限側のゲートとしては使えない。
- 15〜17 歳と 18〜20 歳は原理的に分離できない。境界付近の誤りは前提である。
- 0-5 歳の検出率は群によって 81.2%（Black, n=16）〜 92.2%（Indian, n=64）の幅がある。
  n の小さい群を含む。
- UTKFace の年齢注釈自体の誤りは検証していない。天井精度は注釈ノイズで決まる。
- UTKFace には個人 ID が無く、同一人物が split をまたぐ可能性を排除できていない。
- 姿勢ゲート（|yaw|<=15°, |pitch|<=15°, |roll|<=25°）を通ったフレームでしか評価していない。
